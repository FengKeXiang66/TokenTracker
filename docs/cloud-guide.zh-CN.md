# TokenTracker Pro 说明

TokenTracker Pro 是官方托管 Cloud 服务拟提供的付费会员。Owner 已于 2026-10-09 确认 $4.99/月、$39.99/年的基础价格；生产收费、限制和历史归档尚未开启。付款和账号流程验证后会公布上线日期。[English](cloud-guide.md)

## 继续免费使用

本地采集、所有已支持的 provider、成本估算、额度、本地图表、导出和桌面功能完整免费开源。不登录也能用，本地安装数量不限。

社区榜单、成就和基础公开 Profile 保留。所有账号使用相同排名公式，付款不增加积分倍率，也不会把私有 Profile 改为公开。免费社区上传的更新频率低于 Cloud 同步。

免费社区同步允许每个账号登记 1 台设备，每天上传一次有界批次。本地安装数量不限。Cloud 到期后有多台活跃设备时，可暂停其他设备，选择 1 台继续免费社区同步，历史仍保留。排行榜使用相同的计算规则。

## Cloud 提供什么

Cloud 提供官方托管的跨设备分析服务，已经实现的能力包括：

- 把已登记设备的用量合并查看，按设备、provider、模型和时间范围分析用量与估算费用。
- 通过网页访问同一账号的统计，查看最近 90 天小时明细和 24 个月日汇总，并使用现有云端数据导出。
- 在客户端运行且联网时持续同步，并管理设备暂停与恢复，无需维护自己的服务器。

一个账号覆盖 CLI、macOS、Windows、Linux 和网页，最多登记 5 台同步设备。客户端运行且联网时，有变化的数据每 15 分钟同步一次，可查看最近 90 天小时明细和 24 个月日汇总。CLI 和桌面 App 复用同一已登记的机器标识时只占一个名额，这不属于硬件认证。暂停设备会释放名额并保留历史，恢复时需要有可用名额。

只上传用量指标，不上传 prompt、回复、代码、本地项目/会话记录或 provider 凭证。详情见[隐私政策](PRIVACY.md)。

跨设备月报、预算视图等额外权益会单独评估，目前没有作为已交付功能收费。本地统计、图表和导出仍完整免费。基础价格已确认，正式收款仍需完成工程与资金验收。

## 免费自部署

我们会提供自有 VPS 部署路径，软件免费，服务器、域名、备份和维护由你负责，自有实例不自动接入官方公共榜单。官方 Cloud 的 5 台设备和历史窗口是托管方案限制，不是 MIT 软件许可限制。

目前完整路径仍是技术预览。干净的私有应用安装器、官方本地平台的认证／同步／恢复和标准 Dashboard 实例切换已有验证；公网 VPS HTTPS、原生路由和受审的版本升级仍待完成。见[自部署准备与实现状态](self-hosting.zh-CN.md)，当前不能按“完整 VPS 一键部署已可用”理解。

## 赠送会员

符合条件的已登录账号可在账户设置兑换私下发放的 30、90 或 365 天 Pro 码。一个码只能领取一次，同账号重试不会重复加时；具体起止日期和独立领取记录以服务端为准。赠送不创建 Waffo 付款或自动续费。

领取前先处理未完成付款或已有自动续费。使用中或待生效的礼遇期间不能创建新付费订单，避免期限重叠。停用未领取批次与撤回已领取权益是两项不同管理操作。免费自部署实例不提供官方兑换；正式可用时间以受审发布为准。

## 试用、过渡和到期

- 符合条件的账号可主动开启 7 天试用，不要银行卡，到期不会自动扣费。
- 上线前已有云设备的用户，从公布的上线日期起享有 30 天过渡。账号页会显示准确到期日期，不会自动向旧用户收费。
- 试用、过渡或付费期限到期后，停止个人 Cloud 新数据上传，已有云历史保留 30 天只读和导出。本地统计、社区榜单、成就和基础 Profile 继续可用。
- 导出窗口结束后，个人 Cloud 访问按公开规则处理。90 天小时和 24 个月日汇总指可访问的历史范围。压缩后的用量指标可能保存更久，用于保留和修正公开榜单的累计统计。最终存储和删除时间另行公布，不影响本地数据。

再次按期购买会接在剩余付费期限后。取消自动续费仍可使用已经付费的期限。取消与退款是不同操作，取消不会自动退款。正式上线前会公布最终退款规则和私密客服入口。

账号计费页提供 [Waffo 消费者账单入口](https://pancake.waffo.ai/consumer/portal/login)。请使用购买时填写的邮箱登录 Waffo。TokenTracker 登录状态不会让你自动登录该账单页面。

## 付了钱但没有开通

网页版会在新标签页打开 Waffo 付款页，此处保留订单。桌面 App 会在系统浏览器打开付款页。保持 App 和订单页登录同一 TokenTracker 账号，只在 Waffo 收银台确认付款。付款后返回账号页刷新，服务端核实付款后才开通。成功页、关闭窗口都不能代表最终付款状态。

先查原订单，不要立即重复购买。Waffo 提交购买人信息后，原支付页就可能无法重开，即使付款失败也一样。返回 TokenTracker 订单页，未付款时可选择"关闭本次结账并重新尝试"。服务端会检查原付款状态，关闭未付订单后创建关联的新订单。已经付款或正在处理的付款不能重开。

如果原订单和重试订单都收到了付款，页面会提示重复收款。请查看账单并通过上线时公布的私密计费支持入口处理，暂时不要再次付款。页面仍显示已核实的付款和会员状态，这个提示不代表已经退款。保留订单号和支付凭证，不要把收据、邮箱、账号或交易信息贴到公开 Issue。
